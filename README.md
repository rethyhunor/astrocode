# AstroCode

Public repository for astronomy and astrophotography related tools, scripts, and small software projects by **Hunor Réthy / HunorAstro**.

The repository contains utilities developed primarily for my own astrophotography workflows, experiments, and projects. They are published here in case they may also be useful to other amateur astronomers and astrophotographers.

## Projects

### Seestar Solar Timelapse Stabilizer

A Python-based stabilization tool for solar timelapse image sequences captured with the ZWO Seestar.

It detects the solar disk in individual frames and aligns the images to reduce movement caused by tracking drift and other small positional changes.

Project directory:

[`seestar_solar_timelapse_stabilizer/`](./seestar_solar_timelapse_stabilizer/)

See the project-specific README for installation instructions, usage, and additional details.
